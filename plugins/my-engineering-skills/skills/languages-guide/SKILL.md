# Languages

## For each language, know
- Syntax basics: variables, functions, control flow, collections
- Types: static or dynamic, type hints, null handling
- Error handling: exceptions, result types, error returns
- Package manager and project setup
- Testing framework
- Formatter and linter
- Concurrency model (threads, async, event loop)
- Idioms: how experienced devs write it

## Learning a new language
- Build something small and real, not only tutorials
- Read the official tutorial and style guide
- Read well-regarded open-source code in it
- Practise with small exercises
