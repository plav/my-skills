# Calls and preparation

## Before
- What's the goal of the call? What do I need from it?
- Agenda shared in advance
- Read relevant tickets, docs or code
- Questions written down
- Demo? Test it beforehand and have a backup (screenshots)

## During
- Restate the goal at the start
- Take notes: decisions, actions, owners, dates
- Check understanding: "So we're agreeing that..."
- Park off-topic items
- Keep to time

## After
- Send notes and actions within a day
- Update tickets and docs
- Follow up on your actions

## By type
- Stakeholder: plain language, focus on impact and options
- Technical discussion: diagrams, trade-offs, decision needed
- 1:1: bring wins, blockers, growth topics
- Demo: show the user value first, then details
